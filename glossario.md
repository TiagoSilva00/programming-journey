# Glossário - Programming Journey

Termos técnicos em inglês, com tradução/significado, organizados por
categoria. Atualizado a cada novo conceito estudado.

## 🌐 HTML - Estrutura

| Termo EN         | Tradução/Significado                                      |
|-------------------|------------------------------------------------------------|
| HTML              | HyperText Markup Language - linguagem de marcação usada para estruturar páginas web |
| Tag                | Marcação usada para definir um elemento (ex: `<p>`)        |
| Element / Elemento | Uma tag completa, com abertura, conteúdo e fechamento       |
| Attribute / Atributo | Informação adicional dentro de uma tag (ex: `href`, `src`) |
| DOCTYPE           | Declaração que informa ao navegador qual versão de HTML está sendo usada |
| Head               | Seção com metadados da página, não visível ao usuário       |
| Body               | Seção com todo o conteúdo visível da página                |
| Heading            | Título ou subtítulo (`<h1>` a `<h6>`)                       |
| Paragraph          | Parágrafo de texto (`<p>`)                                  |

## 📋 Listas e Links

| Termo EN         | Tradução/Significado                                      |
|-------------------|--------------------------------------------------------------|
| Unordered List (`<ul>`) | Lista não ordenada, com marcadores (bullets)          |
| Ordered List (`<ol>`)   | Lista ordenada, numerada automaticamente               |
| List Item (`<li>`)     | Cada item dentro de uma lista                            |
| Anchor (`<a>`)          | Tag usada para criar links (âncoras)                    |
| Href (Hypertext Reference) | Atributo que define o destino de um link              |
| Target                 | Atributo que define onde o link será aberto (ex: nova aba) |

## 🛠️ Ferramentas e Ambiente

| Termo EN         | Tradução/Significado                                      |
|-------------------|--------------------------------------------------------------|
| Live Server        | Extensão do VS Code que roda um servidor local para visualizar páginas em tempo real |
| Localhost           | Endereço que representa o próprio computador (ex: 127.0.0.1) |
| Render / Renderizar | Processo do navegador transformar o código HTML em página visual |
